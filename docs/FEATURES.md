## Chromium과 관측 범위

교차 출처 iframe은 각각의 Playwright 프레임에서 수집·조작합니다. open Shadow DOM을 순회하며 closed Shadow DOM 내부 노드는 현재 직접 ID 조작 대상으로 노출하지 않습니다. 브라우저 보안·인증·자동화 차단 정책을 우회하지 않습니다. CAPTCHA 해결, 확장 프로그램 UI, DRM 영상 재생은 구현 범위에 포함하지 않습니다.

무한 스크롤/가상 목록은 Chromium에서 실행됩니다. 스크롤 후 새로 만들어진 DOM을 읽으며 서버에 아직 요청하지 않은 모든 항목을 추측하지 않습니다. `aria-setsize/aria-posinset/aria-rowindex/aria-colindex`와 생략 안내를 제공하고, 해당 컨테이너를 `scroll`한 뒤 재조회합니다.

한 프레임당 DOM 방문은 50,000개, AX 보강은 5,000개로 제한하고 상한 도달을 warnings에 표시합니다. 가림 판단은 중앙점 기반 추정입니다. iframe의 부모 영역에서 발생하는 복잡한 가림이나 CSS 변환은 실제 클릭 검증 결과를 우선합니다. DOM 레이아웃을 계산하므로 Chromium 자체 렌더링 비용이 완전히 사라지는 것은 아닙니다.

`defer`는 **네트워크 image/media 종류**를 차단합니다. script/CSS/font/XHR/fetch는 페이지 동작을 위해 허용하므로 JS가 fetch로 받은 이미지, data/blob URL, 인라인 SVG/Canvas의 디코딩/그리기까지 완전히 억제하지는 않습니다. 서비스 워커를 통한 우회 요청은 defer 프로필에서 차단합니다. 서비스 워커가 필요한 사이트는 새 프로필을 `media_policy=allow`로 시작하세요. 보류 정책이 사이트 동작에 영향을 줄 수 있으며 allow 프로필에서 일반 Chromium 실행에 가까운 호환성을 선택할 수 있습니다.

자동 재생 속성과 미디어 요청을 억제하지만 allow 프로필에서 사이트가 직접 생성한 모든 WebAudio/미디어 동작을 재정의하지는 않습니다. CSS 배경은 텍스트 화면에서 생략되며 명시적 렌더 요청 범위에서 로딩합니다. 페이지가 onerror로 DOM을 교체한 이미지는 이전 노드에 강제로 복원하지 않고 현재 DOM을 다시 탐색합니다.

프로필 데이터는 Chromium 디스크 저장 규칙을 따릅니다. 영속 쿠키와 로컬 저장소는 재시작 시 유지되며 세션 쿠키 만료·서버 로그아웃 정책을 바꾸지 않습니다. 인증 상태는 HTTP 401/403이나 비밀번호 폼의 관측 결과만 표시합니다. 쿠키가 있다고 로그인 성공이라고 추론하지 않습니다. 동일 프로필을 두 프로세스에서 동시에 열면 Chromium 잠금 오류가 발생하므로 Agent마다 다른 data-dir/profile을 사용하세요.

## 이미지 이해

Canvas/WebGL/영상/SVG와 이름상 차트·지도는 `needs_visual`로 시각 확인 필요성을 표시합니다. 원본 래스터 이미지는 원본 픽셀로 렌더하고, SVG/요소/페이지는 Chromium 장치 해상도를 사용합니다. OCR은 설치된 Tesseract와 언어팩으로 수행합니다. 비전 모델 자격 증명은 요구하지 않으며 이미지 의미 해석은 호출 Agent에 맡깁니다.

## 검증과 배포

실제 로컬 HTTP 사이트를 사용하는 통합 테스트가 의미/ID/변경분, 상태/폼, Shadow DOM/교차 출처 iframe, 스크롤/가상 목록, 모달/대화상자/팝업, 포인터/파일, 이미지 보류/렌더, HTTP 오류/방문 기록, 프로필 격리/복원, 잘못된 요청 복구를 검증합니다. 네이티브 빌드에 포함된 Chromium을 `--self-test`로 다시 실행합니다. CI 결과는 [Actions](https://github.com/zzabisagent-lab/AriBrowser/actions)에서 확인할 수 있습니다.

배포 바이너리에는 Chromium·Playwright·Python 런타임이 포함되어 크기가 큽니다. Linux 시스템 공유 라이브러리와 선택적 Tesseract는 번들에 포함하지 않습니다. macOS/Windows 상용 배포 서명 자격 증명은 사용하지 않습니다.
